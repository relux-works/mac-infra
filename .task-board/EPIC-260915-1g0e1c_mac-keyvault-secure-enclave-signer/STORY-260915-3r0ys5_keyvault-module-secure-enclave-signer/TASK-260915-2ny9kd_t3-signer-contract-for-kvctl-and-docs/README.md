(4) Docs: README Tools row and Key Vault section update, SKILL.md section (when to use, ACL prompts the user will see incl. the one-time keychain prompt when the binary changes, keychain vs enclave, extraction policy and that agents never pass --human-authorized, how kvctl selects the macos-keychain backend and the contract version), LOGBOOK entry; setup.sh already builds mac-keyvault (verify).
