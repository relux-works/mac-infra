# EPIC-260519-3glbk7: mac-network-inspector-and-threat-signals

## Description
Evaluate an external-first network/proxy inspection solution before building native mac-infra network monitoring and malware analytics

## Scope
External-first network inspection and threat-signal planning for mac-infra. This epic captures requirements and blocks native implementation until an external solution is evaluated.

## Acceptance Criteria
A requirements brief is linked. Native packet/proxy/MITM implementation is explicitly out of scope until an external-solution review resolves tool choice, privileges, artifact schema, privacy boundaries, and trusted macOS data fields.
